# Product Strategy and Value Proposition

## 1. Core proposition

The platform exists to create practical value from professional membership.

Every major feature must answer:
1. Why should a professional join or remain active?
2. Why should an organization work with MPA?

## 2. Professional value loop

Create identity -> become a member -> complete profile -> verify capability -> become discoverable -> access opportunities -> develop skills -> contribute -> build history -> renew.

Identity gives the person a reusable professional record.

Membership gives a durable relationship with MPA.

Verification changes claims from self-declared to reviewed where evidence is available.

Discovery allows organizations to find relevant professionals.

Opportunity includes jobs, services, mentorship, learning, events and projects.

Contribution includes volunteering, mentoring, teaching, service delivery and project work.

Reputation records verified qualifications, completed programs and participation.

## 3. Stakeholder value loop

Register organization -> verify organization -> discover talent -> create request/opportunity -> receive candidates -> collaborate -> record result -> continue partnership.

The organization should not need to understand MPA administration to use the platform.

## 4. Membership benefits

Benefits should be configurable rather than hard-coded. Examples:
- verified professional directory;
- exclusive jobs;
- mentorship;
- member events;
- member learning;
- professional service listing;
- project participation;
- volunteering;
- achievement record.

Each benefit can have eligibility rules.

## 5. Trust model

Do not make an unexplained single score the main proof of trust.

Prefer understandable signals:
- identity verified;
- profession verified;
- education verified;
- certification verified;
- active member;
- organization verified;
- completed MPA program;
- references where supported.

If a composite score is introduced later, its formula must be documented, versioned and reviewable.

## 6. Public/member/organization value

Public users can discover public professionals, jobs, events, projects and resources.

Members can maintain professional identity, access benefits, apply to eligible exclusive opportunities, request mentorship, learn and participate.

Organizations can search approved talent, create jobs, request services, create events and collaborate on projects.

## 7. Revenue assumptions

Possible revenue sources include membership fees, paid professional programs, training/course fees, selected event fees and institutional partnership services.

The system must separate pricing configuration from payment records.

No commission or marketplace fee should be implemented without explicit business approval.

## 8. Product language

Prefer: verified professional, active member, professional opportunity, organization partner, project participant, verified organization.

Avoid guarantees of employment/income, artificial rankings, unsupported representation claims and unexplained reputation scores.

## 9. Differentiation

The platform should not attempt to become a copy of LinkedIn.

Its value is the combination of membership, trusted professional records, MPA-specific opportunities, mentorship, learning, community participation, project impact and institutional collaboration.

## 10. North-star statement

A member should become more professionally useful and more connected through participation in the MPA ecosystem.

A stakeholder should be able to say: MPA helps us find, develop, engage and mobilize relevant professional capability.
